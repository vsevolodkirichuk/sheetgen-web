## Изменения в osifont

Исходный файл — `osifont-lgpl3fe.ttf`, коммит `2e9aa86` от 16.04.2026. В этой версии глифы `ё`, `Ё` и `Э`
заменены сплошными прямоугольниками. Для лендинга они восстановлены:

- `ё` (U+0451) и `Ё` (U+0401) — копии латинских `ë` и `Ë`, начертание совпадает;
- `Э` (U+042D) — зеркальное отражение украинской `Є` (U+0404).

Остальные глифы не менялись. Файл переконвертирован в WOFF2.
