# Sheetgen Web

Веб-сервис, который строит чертёж детали по её 3D-модели: пользователь загружает STEP или IGES, выбирает стандарт
(ГОСТ, ISO, ASME) и формат листа и получает лист с видами, разрезами, размерами и основной надписью в PNG, PDF или SVG.

Учебный проект курса веб-разработки МФТИ, 2026.

## Этап 2. Лендинг

Каталог `landing/` — статическая страница на чистых HTML, CSS и JavaScript, без фреймворков и сборки.

```
landing/
├── index.html          разметка: шапка, первый экран, проблема, как работает, демо,
│                       возможности, примеры, стандарты, аудитория, вопросы, призыв, подвал
├── css/styles.css      стили и адаптивность (1440 / 1040 / 900 / 640 px)
├── js/main.js          меню на мобильных, просмотр листов в модальном окне
├── js/demo.js          логика демо: выбор стандарта, статусы построения, слои, проверка файла, скачивание SVG
├── js/sheet.js         генератор демо-листа: фланец на A4 по ГОСТ, ISO или ASME в виде SVG
└── assets/             шрифты, изображения листов, favicon
```

### Что есть на странице

- Название, проблема и ценностное предложение на первом экране; размерная линия под заголовком показывает время
  от загрузки до листа.
- Работающее демо: лист фланца строится в браузере по ГОСТ, ISO или ASME (дюймы, третий угол проецирования),
  слои включаются и выключаются, лист скачивается в SVG. Проверка своего файла показывает ту же валидацию,
  что будет в приложении (расширение, размер).
- Примеры настоящих листов, построенных генератором, с просмотром в полном размере.
- Сравнение стандартов, аудитория, ответы на вопросы, призыв к действию.
- Подвал оформлен как основная надпись чертежа.

### Доступность и адаптивность

- Семантическая разметка: `header`, `nav`, `main`, `section` с заголовками, `footer`, `figure`, `details`, `dialog`.
- У всех элементов управления есть подписи; статус построения и сообщения о файле объявляются через `aria-live`.
- Видимый фокус с клавиатуры, ссылка «Перейти к содержанию», учёт `prefers-reduced-motion`.
- Контраст текста не ниже 5:1; аудит axe-core (WCAG 2.1 AA) без нарушений.
- Вёрстка проверена на ширине 390, 820 и 1440 px.

### Локальный запуск

Страница использует ES-модули, поэтому её нужно открывать через локальный сервер, а не как файл:

```bash
cd landing
python3 -m http.server 8000
# открыть http://localhost:8000
```

### Публикация

Workflow `.github/workflows/pages.yml` публикует `landing/` на GitHub Pages при каждом пуше в `main`.
В настройках репозитория: Settings → Pages → Source: **GitHub Actions**.
